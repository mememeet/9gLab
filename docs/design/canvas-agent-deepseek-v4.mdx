# Canvas Agent 默认 DeepSeek V4

画布右侧打开 Agent，运行位置选「网站」，模型保持「平台默认 · DeepSeek V4 Pro」即可对话或调用画布工具，无需填写个人 API Key。

输入 `/` 选择技能，或直接写明技能名称，例如：

> 使用“3D动画短片”技能，为原创白色圆润店员设计 20 秒的商店短片，先输出创作简报和三镜头分镜。

需要指定现有素材时，在 Agent 输入框输入 `@` 选择画布内容，或添加图片附件。单纯选中画布节点只改变选区；画布节点之间已有连线仍按原有生成交互使用参考素材。Skill 加载采用现有入口、目录和文件读取工具，写回画布沿用「确认」开关与撤销机制。

Agent 模型使用独立的 `agentTextModel` 偏好，空值代表从有效平台目录解析 DeepSeek V4 Pro。图片、视频和音频生成继续使用各自的模型配置。手动选定的 Agent 模型如果被停用或移除，会显示错误，不会改用其他模型。
