# 管理员临时代登验证记录

状态：开发与本地自动验证完成；用户已授权合并 main 并部署，发布结果以对应 main 工作流为准，登录态浏览器验收待确认。

## 使用路径与行为

管理员从“用户与运营 → 用户管理 → 用户详情 → 临时代登”填写排查原因，进入目标用户工作区。会话最多 6 小时，且不超过管理员原会话到期时间，顶部展示当前用户、时分秒倒计时、费用归属和“返回管理员”。进入/退出前保存当前修改，切换后重新加载工作区，其他标签页同步刷新。

原密码、目标用户原有会话和最后登录时间保持原值。可查看和修改创作内容，生成按原有流程使用该用户积分；账号身份信息、支付充值、管理员接口被服务端拒绝。管理员原会话失效、降权或禁用，目标用户禁用或提升为管理员，均会使代登拒绝新请求。普通用户、自身、其他管理员、嵌套代登和重复未到期代登均被拒绝。

会话凭据只经 HttpOnly Cookie 传递，支持安全连接的 Secure 与 SameSite=Lax。管理员凭据保留在独立恢复 Cookie 中，代登到期仍可恢复有效的管理员会话；恢复凭据也失效时清除 Cookie 并重新登录。普通业务身份校验头防止旧页面以切换后的身份写入，当前标签页的缓存范围保持原账号归属。

开始/结束和写请求尝试记录在目标用户详情的“管理操作”中，包含真实管理员、目标用户和请求关联标识，不保存请求正文、查询参数或凭据。开始/结束与会话操作原子提交，写请求审计失败则阻止业务执行。代登不伪造目标用户的普通登录/退出事件。
